# Скриншоты для README

Положите сюда картинки со следующими именами — они уже подключены в корневом `README.md`:

- `hero.png` — развёрнутый сайдбар со списком задач (главный, самый крупный скриншот).
- `collapsed.png` — свёрнутое состояние: узкий ярлычок 36×36 у края экрана.
- `editor.png` — открытый модальный редактор описания задачи (с Markdown/CodeMirror).
- `themes.png` — тёмная и светлая темы рядом (можно склеить два скриншота в один коллаж).
- `settings.png` — панель настроек (выбор папки, высота сайдбара и т.д.).

Формат — PNG, ширина ориентировочно 900–1400px, без масштабирования на Retina-дисплеях (иначе картинки будут слишком тяжёлыми).
