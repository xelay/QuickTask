# QuickTask

Минималистичный виджет-панель для ведения заметок и задач на чистом стеке **Python (pywebview) + HTML/CSS/JS**. 

Приложение спроектировано в виде незаметного ярлыка у края рабочего стола, который раскрывается в удобную панель задач по наведению или нажатию горячих клавиш.

---

## Возможности и архитектура

- **Невесомый стек**: Не требует компиляторов C++, Visual Studio Build Tools или тяжелых фреймворков вроде .NET.
- **Хранение в Markdown + YAML**: Все задачи сохраняются как `.md` файлы в настраиваемой папке (по умолчанию `~/Documents/QuickTasks/`). Каждая задача содержит YAML Frontmatter (`done`, `archived`, `created_at`, `updated_at`).
- **Синхронизация через Watchdog**: Реактивное отслеживание любых изменений файлов извне (Obsidian, VS Code, текстовые редакторы).
- **Сайдбар с автоскрытием**:
  - В свернутом состоянии — компактный аккуратный квадратный ярлычок с иконкой (36x36 px) у правого края экрана, не блокирующий клики на рабочем столе.
  - При наведении курсора или клике — плавное физическое разворачивание окна в сайдбар (380 px).
  - Поддержка вертикального перемещения ярлыка (Drag-and-Drop за левую грань) с сохранением позиции в `~/.quicktask/config.json`.
  - Кнопка **Pin** (закрепление окна на экране).
- **Без иконки в панели задач**: Окно отображается в стиле ToolWindow и не захламляет таскбар Windows и меню `Alt + Tab`.
- **Полноценные настройки**:
  - Выбор любой папки хранения задач через системный диалог обзора папок.
  - Настройка высоты сайдбара: если высота фиксированная (например, 700px), окно автоматически центрируется по вертикали с равными отступами сверху и снизу экрана.
- **Темы оформления**: Мгновенное переключение между Темной (Dark) и Светлой (Light) темами одной кнопкой в шапке.
- **Полное закрытие**: Кнопка закрытия приложения в шапке полностью выгружает процесс и освобождает ресурсы ОС.
- **Надежное автосохранение**:
  - Инлайн-редактирование заголовка с автосохранением по вводу (debounce), нажатию Enter или потере фокуса (blur).
  - Переименование файла на диске с защитой от коллизий.
  - Двойной клик по карточке или кнопка с иконкой карандаша открывают модальный редактор подробного описания задачи с поддержкой Markdown и автосохранением по Esc.
- **Глобальный хоткей**: `Ctrl+Alt+T` мгновенно разворачивает сайдбар и открывает фокус на создании новой задачи.

## Быстрый старт (Разработка)

### 1. Клонирование репозитория
```cmd
git clone https://github.com/xelay/QuickTask.git
cd QuickTask
```

### 2. Создание виртуального окружения
```cmd
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей
```cmd
pip install pywebview python-frontmatter watchdog keyboard
```

### 4. Запуск приложения
```cmd
venv\Scripts\python.exe main.py
```
*(Для тихого запуска без консольного окна можно использовать `venv\Scripts\pythonw.exe main.py`)*

## Сборка в самостоятельный EXE-файл

Приложение можно собрать в переносимый `.exe`, работающий автономно без установленного Python.

### 1. Установка PyInstaller
В активном виртуальном окружении выполните:
```cmd
venv\Scripts\pip.exe install pyinstaller
```

### 2. Сборка приложения (Рекомендуемый режим `--onedir`)
Режим папки обеспечивает мгновенный холодный запуск без распаковки во временный каталог:
```cmd
venv\Scripts\pyinstaller.exe --noconsole --name "QuickTask" --add-data "index.html;." main.py
```

- Готовый исполняемый файл и зависимости будут созданы в папке `dist\QuickTask\`.
- Запуск: `dist\QuickTask\QuickTask.exe`.

### 3. Сборка в единый файл (`--onefile`)
Если требуется переносить программу одним файлом:
```cmd
venv\Scripts\pyinstaller.exe --noconsole --onefile --name "QuickTask" --add-data "index.html;." main.py
```
Файл будет создан по пути `dist\QuickTask.exe`.

### 4. Автозагрузка с Windows
Чтобы QuickTask запускался при старте системы:
1. Нажмите `Win + R`, введите `shell:startup` и нажмите `Enter`.
2. Создайте ярлык для `QuickTask.exe` в открывшейся папке автозагрузки.

## Горячие клавиши и управление
- `Ctrl+Alt+T` — развернуть сайдбар и создать новую задачу.
- `Enter` в строке заголовка — применить и сохранить заголовок/имя файла.
- `Клик по карандашу` или `Двойной клик` по карточке — открыть модальный редактор подробного описания задачи.
- `Esc` — закрыть окно описания (с автосохранением), закрыть настройки или свернуть сайдбар.
