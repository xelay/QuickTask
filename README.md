# QuickTask

Виджет-панель для заметок и задач, который живёт незаметным ярлычком у края экрана и разворачивается по клику или хоткею.

![QuickTask](screenshots/quick-task.gif)

## Ключевые функции

- Ярлычок 36×36 px у края экрана, разворачивается в сайдбар (380 px) по наведению курсора, клику или хоткею `Ctrl+Alt+T`; сворачивается сам при потере фокуса.
- Задачи хранятся как обычные `.md`-файлы с YAML-фронтматтером (`done`, `archived`, даты) — открываются в Obsidian, VS Code, любом текстовом редакторе.
- Отслеживание внешних изменений файлов (Watchdog) — правки вне приложения подхватываются на лету.
- Модальный редактор описания задачи с поддержкой Markdown (CodeMirror) и автосохранением.
- Тёмная и светлая темы, переключение одной кнопкой.
- Не занимает место в таскбаре и `Alt+Tab` (окно в стиле ToolWindow).
- Выбор папки хранения задач, настройка высоты сайдбара, перетаскивание и закрепление (**Pin**) ярлычка.

## Системные требования

Windows 10 или 11 (64-bit). Используется системный компонент WebView2 — дополнительно ничего ставить не нужно.

## Установка

Скачайте `QuickTask.exe` со страницы [Releases](https://github.com/xelay/QuickTask/releases) и запустите — Python и другие зависимости не требуются.

Хотите запустить из исходников или собрать `.exe` сами? Инструкция — в [CONTRIBUTING.md](CONTRIBUTING.md).

## Управление

- `Ctrl+Alt+T` — развернуть сайдбар и создать новую задачу.
- `Enter` в строке заголовка — сохранить заголовок/имя файла.
- Клик по карандашу или двойной клик по карточке — открыть редактор описания.
- `Esc` — закрыть редактор описания, настройки или свернуть сайдбар.

## Где хранятся данные

- Задачи — `~/Documents/QuickTasks/` (папку можно сменить в настройках).
- Настройки приложения — `~/.quicktask/config.json`.
